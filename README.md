# InterceptSuite


> [!IMPORTANT]  
> This repository has been archived. The active InterceptSuite codebase is now closed-source and paid-only. See below for details.

## About

InterceptSuite was created to solve a long-standing problem in security testing - intercepting and inspecting **non-HTTP traffic**. While tools for HTTP/HTTPS interception are abundant, security researchers, pentesters, and developers have lacked a reliable way to inspect non-HTTP protocols (raw TCP, TLS, custom protocols, UDP, DTLS, etc.).

InterceptSuite was built to fill this gap - a MITM proxy designed for non-HTTP protocol interception, aimed at pentesting, security testing, and debugging workflows for security teams and developers alike.

## Project History

InterceptSuite was first released as an open-source project on **May 31, 2025**, with the goal of keeping the majority of core features and functionality available in a free, community/open-source version.

On **August 24, 2025**, alongside the community edition, a **Pro version (v1.1.0)** was introduced to help sustain the project - covering ongoing costs of development, maintenance, code signing (Windows & macOS), and testing. The intent was to keep all major and core features available in the free open-source version, while the Pro version funded continued development.

As part of the InterceptSuite ecosystem, a companion open-source project - **ProxyBridge** (a cross-platform proxifier alternative for Windows, Linux, and macOS) - was also created to solve UDP/TCP traffic redirection for thick clients. Maintaining both projects significantly increased development and signing costs over time.

## Transition to Closed Source

On **June 13, 2026**, InterceptSuite transitioned from open-source to **closed-source, with no community/free version** - moving to a Pro-only, paid model.

This decision was necessary to sustain ongoing development of both InterceptSuite and ProxyBridge. Despite the introduction of a Pro tier, revenue did not cover the costs of development, code signing, and infrastructure for either project. As a result, InterceptSuite development was placed on hold for roughly six months. To make continued development sustainable, the project has now moved to a closed-source, paid-only model.

**ProxyBridge remains, and will continue to be, fully open-source.**

## Supporting the Community

While InterceptSuite no longer has a free version, the project still tries to support the community in a few ways:

- **ProxyBridge** will remain fully open-source, with continued development.
- A **trial version** of InterceptSuite Pro is available for evaluation.
- **Students, researchers, or individuals with a valid non-commercial use case** can reach out to **support@interceptsuite.com** with the subject line **"Community License"**. Requests will be reviewed, and if approved, a Pro license key will be provided.

This is our way of ensuring the project remains sustainable while still finding ways to give back to the community.
